## Descriptif README.

# Descriptif du contenu du dépôt:

  <mark>appFAQ:</mark> 
	contient l'application dans son ensemble, le fichier contier les pages PHP et CSS
	<br>
  <mark>BDDappFAQ:</mark> 
	contient le fichier "BDDappFAQ.sql" permettant la création de la base de données
	<br>
  <mark>data appFAQ:</mark> 
	contient le fichier "data.sql" qui permet l'insertion des utilisateurs, admins et super admin



# <mark>Descriptif procédure d'installation (en 3 étapes majeures):</mark> 

<br>
<mark>Avant tout, veuillez installer le fichier appFAQ en zip en cliquant sur l'icone verte (CODE) puis sur download .zip </mark>
<br>

# I-Installation de l'application
<br>
  1.
    Dézipez le fichiers appFAQ.zip sur votre bureau.
		<br>
  2.
    Déplacez le fichier appFAQ dans votre fichier de configuration XAMPP/htdocs/projets/
		<br>
  3.
    Déplacer le fichier BDDappFAQ.sql et déposez le sur votre bureau.
		<br>
  4.
    Déplacer le fichier data.sql et désposez le sur votre bureau.
		<br>
    
# II-Création de la base de données
<br>
  <mark>1.Création appFAQ:</mark>
	<br>
 <br>
      a.
        Lancez XAMPP (MySQL databse et Apache Web Serveur)
				<br>
      b.
        Allez sur votre navigateur.
				<br>
      c.
        Rentrez dans l'URL "localhost".
				<br>
      d.
        Cliquez sur phpMyAdmin dans la navbar.
				<br>
      e.
        Cliquez sur New (sur le coté gauche de votre écran).
				<br>
      f.
        Rentrez dans le champs "Database name" le nom de la base de donnée: appFAQ
				<br>
      g.
        Chosissez le language "utf8mb4_general_ci"
				<br>
      h.
        Cliquez sur CREATE.
				<br>
		<br>
  <mark>2.Importation appFAQ (peuplement)</mark>
	<br>
 	<br>
      a.
        Cliquez sur la base de données sur la gauche de votre écran (elle est à coté d'un symbole cylindrique normalement).
				<br>
      b.
        Cliquez sur importez dans la navbar.
				<br>
      c.
        Selectionnez le fichier BDDappFAQ.sql disponible sur votre bureau.
				<br>
      d.
        Cliquez sur import.
				<br>
      
# III-Insertion des données
<br>
  1.
    Cliquez sur la base de données sur la gauche de votre écran (elle est à coté d'un symbole cylindrique normalement).
		<br>
  2.
    Cliquez sur importez dans la navbar.
		<br>
  3.
    Selectionnez le fichier data.sql disponible sur votre bureau.
		<br>
  4.
    Cliquez sur import.
		<br>
